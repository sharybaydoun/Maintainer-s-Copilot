What it does

Six production primitives, one stack

Each capability is exposed as a typed FastAPI route with structured error envelopes, distributed tracing, and gated thresholds in CI.

🏷️

Issue classification

Three baselines (logistic regression, BERT-tiny, Groq Llama-3.1) evaluated on the same 257-issue test split. The winner is SHA-pinned and enforced at startup.

POST /predict macro F1 SHA-256 gate
🔍

Hybrid RAG

Dense (MiniLM-L6-v2) + BM25 with alpha=0.65, semantic reranker, query rewriting, weak-retrieval refusal, and inline [source] citations.

FAISS BM25 hit@5 / MRR@10
🛠️

Tool-calling chatbot

OpenAI-compatible function calling dispatched in-process: no HTTP self-calls, one trace per turn, five tools, structured tool-failure recovery.

classify_issue search_docs write_memory
🧠

Memory

Redis for short-term per-session turns, pgvector(384) cosine for long-term episodic notes scoped to one authenticated user. Explicit writes only.

Redis pgvector audit log
🔌

Embeddable widget

Dynamic /widget.js loader injects a sandboxed iframe. CSP frame-ancestors is derived per-widget from the allowed_origins allowlist.

React + Vite postMessage CSP gated
📡

Observability

OpenTelemetry → Jaeger, 12 named spans, redaction layer scrubs 7 token patterns + 10 sensitive keys before logs, traces, or persisted memory.

OTLP/HTTP JSON logs trace_id ↔ logs

RAG + chatbot lifecycle

What happens when you ask a question

One POST /chat turn fans out into a multi-span trace you can open in Jaeger. Every step is gated, redacted, and logged.

Safety check Prompt-injection filter rejects unsafe queries.
Tool routing LLM picks one of 5 in-process tools.
Hybrid retrieve Dense + BM25, alpha=0.65, top-10.
Rerank Semantic reranker keeps top-5.
Grounded answer LLM cites [source] tokens only.
Redact + persist Memory + audit row written atomically.
